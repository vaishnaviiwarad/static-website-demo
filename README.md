## 🚀 How This Website Was Deployed

1. **Created Files**: Created an `index.html` file with semantic HTML and a `style.css` file for styling.
2. **Pushed to GitHub**: Initialized a Git repository and pushed to the `main` branch of `https://github.com/vaishnaviiwarad/static-website-demo`.
3. **Enabled GitHub Pages**:
   - Navigated to repository **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, selected **Deploy from a branch**.
   - Selected branch: `main` and folder: `/ (root)`.
   - Clicked **Save**.
4. **Verified Live Site**: Accessed the generated GitHub Pages URL provided in the settings.
